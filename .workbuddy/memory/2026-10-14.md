# 2026-10-14 工作日志

## 菜单⑮（配置花蕊 LeavePanel4）报错修复
- 现象：点 Tools→古画教学→⑮ 报 `Object at index 0 is null`（SerializedObject.InternalCreate），配置中断、预制体没保存
- 根因：LeavePanel4 预制体**根物体上已残留一个 LeafPaintStep**（复制面板时带过来的），而 StepBase 带 `[DisallowMultipleComponent]`，导致 `Undo.AddComponent<StamenPaintStep>(root)` 被拒返回 null → `new SerializedObject(null)` 抛异常
- 修复（SceneSetupTools.ConfigureStamenCore）：配置前先 `root.GetComponents<StepBase>()` 逐个 `DestroyImmediate` 清掉旧步骤脚本，再挂 StamenPaintStep；挂载失败抛明确异常
- 校验：14 文件离线编译 0 错误
- 教训（通用）：凡往面板根上 AddComponent<StepBase派生>，必须先清掉根上已有的其他 StepBase 派生脚本；否则 DisallowMultipleComponent 静默拦截、AddComponent 返回 null，后续 SerializedObject(null) 报"Object at index 0 is null"
