# 步骤 ② 叶子涂色 · 使用说明

> 项目：Draw Flower　/　Unity 2022.3.62f3c1　/　已通过离线编译校验（0 错误 0 警告）

---

## 〇、最快上手（4 步）

1. 菜单 **Tools → 古画教学 → ⑤ 把叶子面板放进 SampleScene**　→　看到「已经完成」
2. 菜单 **Tools → 古画教学 → ⑧ 按 lightImage 位置给脉络加碰撞盒**　→　**新建 8 个 Area_1-1 ~ Area_1-8**，每个都有 BoxCollider2D
3. 菜单 **Tools → 古画教学 → ⑥ 创建/修复 GameFlow 流程控制器**　→　看到「已创建 GameFlow」
4. 菜单 **Tools → 古画教学 → ⑨ 叶子涂色步骤 · 配置向导**　→　自动配 area / lightImage / Next 按钮 → 点「写入脚本」

然后 ▶ Play 即可：① 选墨色 → ② 涂色（浅+深）。

> **重要**：为什么不用「把 BoxCollider2D 直接挂在 1-X 图片上」？因为 lightImage 初始 `SetActive(false)`，**挂失活 GameObject 上的 Collider2D 不响应 Physics2D 查询**（这是 Unity 的规则）。所以 area 用独立的 `Area_<id>` 兄弟节点，**永远保持激活**。

---

## 一、这一步实现了什么

| 行为 | 效果 |
|---|---|
| 鼠标左键长按 + 拖拽到 1-1 区域 | 该脉络上 `lightImage`（1-1.png）激活 |
| 在 1-1 上松开，再次按住拖到 1-2 | 1-2.png 出现（一次按压只染一个） |
| 8 个脉络全部填完 | **Next 按钮从灰变绿可点** |
| 点 Next | 进入**加深**模式：8 个脉络恢复空白 |
| 在 1-1 拖一下 | 这次显示 `deepImage`（1-1-deep.png），叠加在第一遍上面 |
| 8 个加深脉络全部填完 | Next 按钮再次变绿可点 |
| 点 Next | 抛 `onStepCompleted`，GameFlow 推进到下一步 |

## 二、LeavePanel 预制体结构要求

```
LeavePanel  ← 在这里挂 LeafPaintStep
└─ Canvas
   ├─ line-drawing  (线稿)
   ├─ highlight     (第一片叶子高亮)
   ├─ 1-1           (RectTransform + Image + 你的 lightImage.png 资源)
   │  ├─ lightImage (Image, 初始 SetActive(false))
   │  └─ deepImage  (Image, 初始 SetActive(false))
   ├─ Area_1-1      (RectTransform + BoxCollider2D, 始终激活)
   ├─ 1-2 + Area_1-2
   ├─ … (1-3 ~ 1-8 同样结构)
   └─ NextButton    (Button + Image)
```

脉络区域叫 `1-1`、`1-2`、…`1-8`（中间一个 `-`），图片子物体叫 `lightImage` / `deepImage`，向导的「按 id 批量配」按钮就能一键配好。

如果你用的是多片叶子，`2-1`、`2-2` 这种命名也支持——只要名字是「叶子-脉络」两个数字加 `-`。

## 四、菜单一览（新加的）

| 菜单 | 干啥 |
|---|---|
| **⑤ 把叶子面板放进 SampleScene** | 同 0⃣。打开 SampleScene → 找 LeavePanel 预制体 → 实例化 → 挂 LeafPaintStep → 建 EventSystem → 保存 |
| **⑥ 创建/修复 GameFlow 流程控制器** | 在场景里建一个空 GameObject 挂 GameFlow，自动写两个步骤的引用（[0]=墨色、[1]=涂色） |
| **⑦ 把叶子涂色诊断打印到 Console** | 输出：找到几个脉络、几个配了 area / lightImage / deepImage、Next 按钮有没有 |
| **⑨ 叶子涂色步骤 · 配置向导** | 8 个脉络批量配 + 写入 |

GameFlow 配好后有这些 Inspector 字段（场景里选中 GameFlow 物体）：

| 字段 | 说明 |
|---|---|
| Steps[] | 步骤数组，**下标 0 = 墨色，下标 1 = 涂色**。每个元素含 container（步骤所在 GameObject）+ step（自动从 container 找） |
| Use Debug Start | 勾上后用 debugStartIndex 作为起始步骤（测试用） |
| On All Completed | 全部步骤完成后触发，可以挂个"完成画面"或重新开始游戏 |

## 五、LeafPaintStep 参数速查

| 分组 | 字段 | 说明 |
|---|---|---|
| 脉络 | Veins | 8 个 VeinSlot，每个含 id / area / lightImage / deepImage |
| 模式 | Current Mode | Light 或 Deep。运行时由 Next 按钮切换 |
| 高亮 | Highlight Overlay | 第一片叶子轮廓的高亮图。两遍都显示，如果你想加深时高亮消失，把这里留空 |
| Next 按钮 | Next Button | 涂完前不可点（interactable=false、颜色灰）；涂完变绿可点 |
| | Enabled/Disabled Color | 可点 / 不可点状态的颜色，默认 (0.4,0.85,0.4) 和 (0.7,0.7,0.7,0.5) |
| | Enabled/Disabled Sprite | 可选，给按钮准备两张图做状态切换 |
| 输入 | Long Press Duration | 长按多久才认（秒），默认 0.15s |
| | Drag Threshold Px | 拖拽多少像素才认，默认 6px |
| 反馈 | Vein Done Clip | 每个脉络涂对时的音效，可选 |
| | Vein Done Volume | 音量，默认 0.6 |
| 事件 | onVeinColored | 每涂对一条脉络触发一次 |
| | onAllLightDone | 浅涂全部填完 |
| | onAllDeepDone | 加深全部填完 |
| | onModeChanged(string) | 模式切换（"Light"/"Deep"） |
| | onStepCompleted | 继承自 StepBase：两遍全填完 + 点 Next → 触发 |

## 六、怎么验证（在你试之前我自己会做的）

**编译校验**：12 个文件 0 错误 0 警告（我刚跑过）。

**运行验证清单**（你做一下）：

1. ▶ Play 后，墨色步骤能正常选（这一步 ① 之前应该已经通过）
2. 选对墨色后，5 个墨色按钮淡出，**自动**切到 LeavePanel（应当出现"对叶子进行加深"的提示）
3. LeavePanel 上第一片叶子高亮
4. 在 1-1 区域长按 + 拖一下，1-1 的 lightImage 出现
5. 松开后再按 1-2，1-2 lightImage 出现
6. 把 8 个都涂完，Next 按钮变绿
7. 点 Next，8 个 lightImage 还在，加深脉络开始工作
8. 在 1-1 长按拖一下，1-1 的 deepImage 出现（叠加在 lightImage 上面）
9. 8 个 deepImage 都填完，Next 再次变绿
10. 点 Next，抛 onStepCompleted

如果哪一步出岔，按 `Tools → 古画教学 → ⑦ 把叶子涂色诊断打印到 Console`，把 Console 内容贴给我。

## 七、想自己改两个关键参数

**改涂色触发条件（更松 / 更严）**：Hierarchy 里选中 LeavePanel 根 → 右侧 Inspector 找到 **LeafPaintStep** 组件 → **⑤ 输入判定** 一栏：
- `Long Press Duration`：默认 0.15s，调大=更严
- `Drag Threshold Px`：默认 6 像素，调大=需要拖更远才认

**改加深脉络的视觉**：直接在 prefab 里把 1-1~1-8 下面的 `deepImage` 物体的 Sprite 换成你想要的更深的图、或者调它的颜色 / 不透明度。

## 八、给 GameFlow 加第三步

如果以后想加"第三步：花瓣涂色"等，结构是这样：

1. 做一个新预制体 `FlowerPanel`
2. 在 GameFlow 的 Steps[] 里把 array size 改成 3
3. 把 FlowerPanel 实例拖到第 2 项的 container

GameFlow 会自动按 [0]→[1]→[2] 顺序执行，前一步完成自动激活下一步所在的 GameObject。
